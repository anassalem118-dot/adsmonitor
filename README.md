# 📊 منصة مراقبة اعلانات ميتا (نسخة مجانية 100%)

لوحة ويب + تنبيهات تيليجرام يومية. **بدون سيرفر وبدون استضافة مدفوعة.**

```
┌─────────────────┐   كل ساعة    ┌──────────────┐        ┌──────────────────┐
│ GitHub Actions  │ ───────────▶ │  Supabase    │ ◀───── │ Streamlit Cloud  │
│ (المهمة اليومية)│  يكتب/يقرأ   │  (Postgres)  │ يقرأ   │ (اللوحة + الدخول)│
└────────┬────────┘              └──────────────┘        └──────────────────┘
         │ تنبيهات
         ▼
     Telegram
```

- **GitHub Actions** بيشغّل `run_daily.py` كل ساعة؛ هو بقرر اذا لازم يشتغل (حسب «ساعة التشغيل» اللي بتحطها من الاعدادات).
- **Supabase** بيخزن كل شي (المستخدمين، الحسابات، التوكنات المشفّرة، الارقام، التنبيهات).
- **Streamlit Cloud** بيعرض اللوحة. اذا نامت (بعد 12 ساعة بدون زيارة) **التنبيهات بتضل شغالة** لانها من GitHub.

> بدل APScheduler صار الجدولة عن طريق GitHub (لانو Streamlit Cloud بينام وما بصلح يشغّل مهام خلفية).

## 🚀 الاعداد خطوة بخطوة (حوالي 20 دقيقة)

### 1) Supabase (القاعدة)
1. سجّل في supabase.com ← **New project** (اختار منطقة قريبة، واحفظ كلمة مرور القاعدة).
2. بعد ما يجهز المشروع: زر **Connect** ← اختار **Session pooler** ← انسخ رابط الـ URI.
   - ⚠️ لازم **Session pooler**، مش *Direct connection*: الاتصال المباشر IPv6 بس، وGitHub وStreamlit بيشتغلوا على IPv4.
3. بدّل `[YOUR-PASSWORD]` في الرابط بكلمة مرور القاعدة. هاد هو `DATABASE_URL`.

### 2) GitHub (الكود + المهمة اليومية)
1. انشئ مستودع **Private** جديد وارفع محتوى هالمجلد كله (بما فيها `.github/`).
2. من المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**، وضيف:
   - `DATABASE_URL` = رابط Supabase
   - `SECRET_KEY` = مفتاح التشفير (بتولّده في الخطوة 3)

### 3) Streamlit Community Cloud (اللوحة)
1. على share.streamlit.io سجّل بحساب GitHub ← **Create app** ← اختار المستودع ← Main file: `app.py`.
2. في **Advanced settings ← Secrets** حط:
   ```toml
   DATABASE_URL = "رابط Supabase"
   ```
3. اضغط Deploy. اول ما تفتح اللوحة رح تقلك «ما لقيت SECRET_KEY» وتعطيك سطر جاهز — انسخه وحطه في **Secrets** (Streamlit) وكمان في **GitHub Secrets** باسم `SECRET_KEY`. **لازم نفس القيمة بالضبط في الاثنين.**
   - احفظ المفتاح بمكان امين. اذا ضاع بتلصق التوكنات من جديد.

### 4) اول استخدام
1. افتح اللوحة ← انشئ حساب المدير.
2. **Accounts**: الصق توكن ميتا ← «اجلب كل حساباتي» ← اختار ← «اضف المحدد» ← «تحميل آخر 30 يوم».
3. **Telegram**: الصق توكن البوت (من @BotFather) ← ابعت `/start` للبوت ← «التقط المحادثة اوتوماتيك» ← رسالة تجريبية.
4. **Settings**: حدد ساعة التشغيل والمنطقة الزمنية وحدود التنبيه.
5. جرّب المهمة: GitHub ← تبويب **Actions** ← *Daily Meta Ads Check* ← **Run workflow**.
   لازم تنجح (✅) وتشوف الارقام في اللوحة.

### كيف تجيب توكن ميتا
الافضل **System User Token** (ما بنتهي بسرعة): Meta Business Settings ← Users ← System Users ← اضف System User ← اعطيه وصول للحسابات الاعلانية ← Generate Token بصلاحية `ads_read`.

## 💰 حدود المجاني (راجعها قبل ما تعتمد عليها، بتتغير احيانًا)
- **GitHub Actions**: 2,000 دقيقة/شهر للمستودعات الخاصة. التشغيل كل ساعة ≈ 700 دقيقة/شهر، يعني مرتاح.
  اذا بدك توفر: غيّر سطر `cron` في `daily.yml` لمرة باليوم، مثلًا `"0 5 * * *"` (الساعة 5 UTC = 8 صباحًا بتوقيت عمّان)، وخلّي «ساعة التشغيل» في الاعدادات 8 او اقل.
- **Supabase**: 500MB للقاعدة، والمشروع بيتوقف اذا ما في نشاط اسبوع — بس المهمة بتحكي مع القاعدة كل ساعة فما رح يتوقف.
- **Streamlit Cloud**: تطبيق خاص واحد مجاني (وهاد مستودعك الخاص). بينام بعد 12 ساعة بدون زيارة، وبيصحى لما تفتحه.
- GitHub ممكن يوقف الجدولة اذا ما في اي نشاط على المستودع فترة طويلة (حوالي شهرين): بين فترة وفترة افتح تبويب Actions وتأكد انها شغالة.

## 🔐 الامان
- التوكنات مشفّرة (Fernet) قبل ما تنحفظ، وكلمات المرور بـ bcrypt.
- فعّلنا **Row Level Security** على كل الجداول، يعني ما حدا بقدر يوصلها من Supabase REST API حتى لو عرف مفتاح `anon`.
- لا ترفع `secrets.toml` الحقيقي على GitHub (هو مستثنى في `.gitignore`).
- المستخدمين الجداد بينضافوا بس من صفحة Settings.

## ⚠️ ملاحظة صريحة
جرّبت منطق التحليل وشرط التشغيل (الساعة/مرة باليوم/اعادة المحاولة عند الفشل) باختبارات محلية، بس **ما قدرت اجرّب الاتصال الحقيقي مع Supabase وميتا وتيليجرام** (ما في انترنت عندي). اول تشغيل جرّبه بحساب واحد وقارن الارقام مع Ads Manager، وإذا طلع اي خطأ في Actions ابعتلي نص الخطأ.
